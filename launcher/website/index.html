Ton système va peut-être tiquer, c'est normal.

1999 n'est pas encore signé par Microsoft ni par Apple. Voici comment passer l'avertissement la première fois.

  1. Décompresse le .zip téléchargé (clic droit › Extraire tout), puis double-clique sur 1999.exe.
  2. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires.
  3. Clique ensuite sur Exécuter quand même. 1999 s'installe et s'ouvre tout seul.
Windows a protégé votre ordinateur Microsoft Defender SmartScreen a empêché le démarrage d'une application non reconnue. Informations complémentaires Exécuter quand même
  1. Ouvre le .dmg et glisse 1999 dans le dossier Applications.
  2. Dans Applications, fais un clic droit sur 1999 (ou Ctrl + clic), puis Ouvrir.
  3. Confirme avec Ouvrir dans la fenêtre qui apparaît. Les fois suivantes, un double-clic suffit.

La version Mac arrive bientôt : le bouton s'activera tout seul dès qu'elle sera en ligne.

  1. Décompresse l'archive téléchargée : elle contient un dossier 1999.
  2. Dans ce dossier, double-clique sur launcher-1999, ou lance-le depuis un terminal :
tar -xzf 1999-Setup-*-linux-x64.tar.gz
cd 1999
./launcher-1999

S'il refuse de démarrer, rends-le exécutable avec chmod +x launcher-1999.
